# 门禁访客系统

## 项目概述

门禁访客系统是一个基于Vue 3 + Element Plus开发的现代化访客管理系统，用于管理访客登记、签到签退、访问记录等功能。

## 技术栈

- **前端框架**：Vue 3
- **构建工具**：Vite
- **UI组件库**：Element Plus
- **路由管理**：Vue Router
- **数据存储**：localStorage（模拟后端存储）

## 功能模块

### 1. 登录系统
- 用户名：admin
- 密码：123456
- 登录后进入系统仪表盘

### 2. 访客登记
- 填写访客基本信息（姓名、身份证号、联系电话）
- 选择访问日期、时间和事由
- 填写被访人信息
- 提交后自动生成访客记录

### 3. 访客管理
- 查看所有已登记的访客
- 支持搜索访客姓名或身份证号
- 支持访客签到和签退操作
- 支持删除访客记录

### 4. 访问记录
- 查看所有访客的访问记录（登记、签到、签退）
- 支持按日期范围筛选记录
- 记录详细的操作时间和类型

### 5. 系统设置
- 基本设置：修改系统名称、管理员名称、联系电话、系统Logo
- 安全设置：修改管理员密码
- 数据管理：导出数据、清空数据

## 项目结构

```
src/
├── router/          # 路由配置
├── views/           # 页面组件
│   ├── Login.vue    # 登录页面
│   ├── Dashboard.vue # 仪表盘
│   ├── Register.vue # 访客登记
│   ├── Visitors.vue # 访客管理
│   ├── Records.vue  # 访问记录
│   └── Settings.vue # 系统设置
├── App.vue          # 根组件
└── main.js          # 入口文件
```

## 安装和运行

### 安装依赖

```bash
npm install
```

### 开发环境运行

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 注意事项

1. 本系统使用localStorage进行数据存储，刷新页面后数据会保留，但清除浏览器缓存会导致数据丢失
2. 实际生产环境中，建议使用后端数据库存储数据
3. 系统默认管理员账号：admin，密码：123456
